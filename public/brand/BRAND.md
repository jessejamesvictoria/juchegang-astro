# JucheGang Brand Kit

## Archetype
Swiss Industrial Print. Blueprint documentation substrate with hazard-red telemetry accents.

## Palette
| Token | Hex | Usage |
|-------|-----|-------|
| Paper | `#F4F4F0` | Page background |
| Ink | `#050505` | Primary text, borders |
| Hazard | `#E61919` | Accent, crosshairs, vital data |
| Muted | `#6B6B66` | Secondary metadata |

## Typography
- **Macro:** Archivo Black, uppercase, tight tracking
- **Micro:** IBM Plex Mono, uppercase, wide tracking
- **Korean:** Noto Sans KR

## Geometry
- Zero border-radius on all elements
- 1px and 2px solid borders only
- No gradients, no drop shadows
